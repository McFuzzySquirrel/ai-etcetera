# Knowledge graph artifacts

This directory holds Dirk's knowledge-graph outputs:

- `graph.db`   — SQLite store (the source of truth across runs)
- `graph.json` — portable Cytoscape.js export
- `graph.html` — static interactive viewer; open it in a browser

These files are **regenerated** on every `dirk run`. Do not edit them by
hand.

Until the first scan completes the directory will be empty apart from this
README — that is expected.
