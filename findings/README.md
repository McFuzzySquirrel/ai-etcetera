# Findings

Dirk writes its human-facing reports here:

- `YYYY-MM-DD-findings.md` — full report for a given run.
- `latest.md`              — pointer to the most recent report.
- `delta-YYYY-MM-DD.md`    — what changed since the previous run.

Reports are **regenerated** on every `dirk run`. Do not edit them by hand —
add a skill instead.
